## Overview

Whisper is OpenAI's open-source automatic speech recognition model, available in five sizes from tiny to large-v3, providing state-of-the-art transcription accuracy across 99 languages with optional translation to English. Running fully locally via the whisper Python package or optimized ports like whisper.cpp, it is the backbone of countless transcription workflows.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Whisper** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **99 Languages** | High-accuracy transcription across 99 spoken languages |
| **Translation** | Automatic translation of any supported language to English |
| **Five Model Sizes** | Tiny to Large-v3 models balancing speed versus accuracy |
| **whisper.cpp** | Optimized C++ port with GPU support for fast local inference |
